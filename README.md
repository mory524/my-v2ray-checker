# 🚀 V2Ray Config Checker Pro

**ابزار حرفه‌ای، سریع و آفلاین برای تست و فیلتر کانفیگ‌های V2Ray (VMess, VLess, Trojan) به همراه تولید QR Code و قابلیت نصب روی گوشی (PWA/APK)**

## ✨ ویژگی‌های کلیدی

- **تست خودکار** بدون نیاز به وارد کردن کانفیگ – فقط کافیست یک دکمه را بزنید.
- **تست دستی** برای کانفیگ‌های دلخواه شما (پشتیبانی از vmess://, vless://, trojan://).
- **نمایش ۵ کانفیگ برتر** بر اساس کمترین تأخیر (latency) به همراه QR Code قابل اسکن.
- **ذخیره‌سازی کانفیگ‌های زنده** در فایل متنی با یک کلیک.
- **رابط کاربری مدرن و واکن‌گرا** با سه تب مجزا (خودکار، دستی، برترین‌ها).
- **قابلیت نصب روی گوشی** به صورت Progressive Web App (PWA) روی iOS و Android.
- **بدون نیاز به اینترنت** برای اجرای برنامه (فقط برای تست کانفیگ نیاز به اتصال دارد).
- **سبک و سریع** – حجم نهایی کمتر از ۳ مگابایت.

## 🔧 نحوه استفاده

1. **تب اول (تست خودکار)**: دکمه «شروع تست خودکار» را بزنید. برنامه به طور خودکار کانفیگ‌ها را از ۸ منبع معتبر دریافت کرده و زنده بودن آنها را بررسی می‌کند.
2. **تب دوم (تست دستی)**: کانفیگ دلخواه خود را در کادر متنی جایگذاری کرده و روی «تست کانفیگ» کلیک کنید.
3. **تب سوم (۵ کانفیگ برتر)**: پس از اتمام تست خودکار، این تب به‌طور خودکار بهترین کانفیگ‌ها را با کمترین تأخیر نمایش می‌دهد. برای هر کانفیگ یک QR Code قابل اسکن وجود دارد.

## 📱 نصب روی گوشی

- **اندروید**: با Chrome به آدرس برنامه بروید و گزینه «Install app» یا «Add to Home Screen» را انتخاب کنید.
- **آیفون (iOS)**: با Safari به آدرس برنامه بروید، دکمه Share را بزنید و «Add to Home Screen» را انتخاب کنید.

## 🖥️ نصب روی ویندوز/مک/لینوکس

فایل `index.html` را در هر مرورگر مدرنی باز کنید. برای اجرای آفلاین، می‌توانید از یک سرور محلی ساده (مثل `python -m http.server`) استفاده کنید.

## 📦 خروجی‌ها

- ذخیره لیست کانفیگ‌های زنده در فایل `.txt`
- ذخیره QR Code هر کانفیگ به صورت تصویر `.png`
- کپی مستقیم کانفیگ در کلیپ‌بورد

## 🛠️ تکنولوژی‌های استفاده شده

- HTML5, CSS3, JavaScript (ES6)
- PWA (مانیفست، Service Worker)
- QRCode.js برای تولید QR Code
- Fetch API و WebSocket برای تست اتصال
